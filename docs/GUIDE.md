## 画面

| 画面 | 代表什么 |
|---|---|
| 火羽鸟 | 火羽ひのめ。飞到哪一年，就是那时的样子：会长大、换羽 |
| 鸟居 | 她播过的一夜 |
| 素木的门 | 只有预告、没有直播记录的日子 |
| 插火羽的门 | 大事的夜：纪念日、生日、周年，或弹幕特别多、播得特别久；最后一座门也是 |
| 神額 | 那一夜的日期；每年第一座门写年份 |
| 门柱上的字 | 那一夜弹幕里真有人说过的话。正面的句数是当夜说话的人数，背面是说晚安的人数 |
| 金字 | 写成金色的那部分，是当夜一年以上老观众的比例 |
| 冷白色的字 | 负面的话；风波那几周（2022-10-12 到 11-07）放大写 |
| 磨花的字 | 只有人数、没有逐条弹幕的夜 |
| 小鸟 | 大航海人数，每人一只；按人数和陪伴天数分档，不对应具体的人 |
| 天气 | 那些夜里弹幕的情绪 |
| 雾 | 直播存档的缺口（2023-09-01 到 2025-07-25） |
| 太阳 | 人数涨得最多的那一夜升起 |
| 「鸣」的牌子 | 那一夜的直播标题 |

## 操作

| 操作 | 作用 |
|---|---|
| 「停」、空格 | 暂停、继续 |
| 近看门柱、绕到柱后 | 暂停时近看这一夜的门柱，绕到背面 |
| 借一道闪电 | 暂停时，闪电里亮起负面的话 |
| 寻声 | 按情绪找夜，「前夜」「后夜」逐个跳 |
| 快慢 | 缓飞、常飞、疾飞、迅飞 |
| 声 | 开关声音；碰过页面后才有声音 |
| 静 | 减少动态 |
| 回到今天 | 跳回今天 |
| 从头飞起 | 从 2021 年飞到今天 |
| 电影模式 | 去掉界面从头放映，最后飞向太阳 |
| 拖动 | 绕着她转 |
| 滚轮、双指 | 拉近 |
| 方向键 | 逐日移动，按住 Shift 一次 30 天 |
